## 💻 Commands & Skills Practiced Today

### 1. File & Directory Management
* `touch` — Created empty files and updated existing file timestamps.
* `cd` — Navigated between directories and key file system paths.
* `ls` — Listed directory contents and viewed hidden files and permissions using flags like `-l` and `-a`.
* `cp` — Copied files and directories across different locations.
* `mv` — Renamed files and moved items across the file system structure.

### 2. User Account Administration
* `useradd` — Created new user accounts, set up home directories, and configured initial user configurations.
* `userdel` — Safely removed user accounts and cleaned up user directories.

### 3. Archiving & Compression
* `tar` — Combined multiple files into archive bundles (`tar -cvf`) and extracted packed files (`tar -xvf`).
