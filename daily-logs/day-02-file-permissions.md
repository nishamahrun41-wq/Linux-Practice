## 📝 Practice Log & Commands

### 1. File & Directory Management
- `cp` — Copies files or directories from one location to another.
- `mv` — Moves or renames files and directories.
- `rm` — Removes (deletes) individual files.
- `rm -r` — Recursively removes directories and all their contents.

### 2. Viewing & Inspecting File Contents
- `cat` — Displays the complete contents of a text file.
- `head` — Outputs the first few lines of a file (default: top 10 lines).
- `tail` — Outputs the last few lines of a file (default: bottom 10 lines).

### 3. File Comparison & Labs
- `diff` — Compares two files line-by-line and highlights differences.
